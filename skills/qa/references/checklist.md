# QA 체크리스트

각 화면을 아래 8개 기준으로 평가한다.

## 1. 한글 카피
- 어색한 번역투·오타·맞춤법
- 톤(존댓/반말) 불일치
- 이해 안 되는 에러 메시지

## 2. 영문 카피
- 어색한 직역투
- 한글과 정보량 불일치

## 3. 디자인 느낌
- 첫인상
- 색상/타이포/여백 일관성
- 브랜드 톤 유지

## 4. 가독성
- 자간·행간·글자 크기
- 명도 대비 (라이트/다크)
- 긴 글 읽기 편함

## 5. 퍼포먼스
- 페이지 전환 체감 (빠름/보통/느림)
- 리스트 렌더링
- 에디터 반응 속도 (타이핑·스크롤 버벅임)
- 이미지/영상 로딩, 검색 속도

## 6. UI/UX 느낌
- 첫 사용에 길 잃음 여부
- 클릭 가능 요소 구분
- 로딩/빈/에러 상태 처리
- 되돌리기(취소·뒤로) 쉬움

## 7. 사용성
- 핵심 태스크 완수 여부 (글쓰기→발행·공유·설정)
- 완수까지 단계 수
- 모바일에서 완수 가능 여부

## 8. 차별점
- 경쟁 서비스 대비 강점으로 느껴진 순간
- 불편했던 순간과 구분해 기록
