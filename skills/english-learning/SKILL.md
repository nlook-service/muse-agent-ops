# english-learning

## Purpose
매일 정해진 시간(예: 07시·13시·18시)에 영어 뉴스 기사를 하나 골라
중급 학습자(해외 체류 경험, 기본 회화 가능) 수준의 학습 문서를 만들어 등록한다.
회차마다 다른 기사·다른 분야를 고른다.

## Workflow

### 1. 기사 선정
- 최근 24~48시간 이내 보도된 영어 뉴스 1편
- 분야 순환: 철학·사회·역사·심리·교육·국제관계·문화·예술·과학·기술·경제·환경·건강·스포츠
  (IT에만 치우치지 말 것)
- 소스: AP·Reuters·BBC·NPR·The Guardian·CNN 등 주요 매체
- **중복 방지**: 당일 이미 등록된 문서 목록을 먼저 조회하고 같은 기사·같은 분야는 피한다
- 기사 원문을 실제로 읽고 발췌에 사용한다

### 2. 대표 이미지
- 주제 영어 키워드로 이미지 검색 → 200 응답·image content-type 확인
- 워터마크·깨진 이미지 제외, 문서 상단에 `![설명](URL)` 형태로 삽입

### 3. 학습 문서 작성 (Markdown)
중급 수준에 맞는 문장만 고른다 (지나치게 전문적·난해한 문장 제외).
**표(table) 금지, 리스트 사용.** 15~20분 분량.

구성 (원문 전체를 통째로 먼저, 해설은 그 다음):
- `# 헤드라인(영어 원제)` + 한국어 제목 한 줄 + 출처 링크 + 보도 날짜 + 대표 이미지
- `## 원문 전체`: 기사에서 발췌한 6~8개 문장을 순서대로 통째로 인용. **이 섹션에 한국어 한 글자도 넣지 않는다**
- `## 문장별 뜯어보기`: 같은 순서로 번호 목록. 각 영어 문장 아래 `- 해석:` 한국어 해석, 그 아래 `- 중요 표현:` 으로 단어·구 2~4개를 **굵은 글씨**로 + 괄호 안에 한국어 뜻
- `## 핵심 문장 6~10개`: 같은 형식
- `## 오늘의 단어 12~15개`: 영어 단어 - 한국어 뜻 - 짧은 예문
- `## 유용한 표현 3~5개`: 쓰임 설명 + 예문
- `## 생각해보기`: 영어로 답해볼 질문 2개

### 4. 등록
- Markdown을 `/tmp/english-study-YYYY-MM-DD-HH.md` 로 저장
- 문서 백엔드에 등록 (제목: `영어 학습 YYYY-MM-DD HH시: <헤드라인>`, 태그: `english-study`, `news`, `<분야>`)
- 백엔드 선택: 로컬 파일 / nlook MCP / REST API — `references/doc-backend.md` 참고
- 등록 성공 여부를 출력으로 확인

### 5. 보고
짧게: 오늘의 뉴스 주제 한 줄, 핵심 문장 2~3개(해석 포함), 등록된 문서 제목.
전체 콘텐츠는 문서 서비스에서 보라고 안내.

## Operating Rules
1. 하루 3회 실행 시 기사·분야가 겹치지 않게 한다
2. 원문을 통째로 옮기지 않고 발췌만 사용한다 (6~8문장)
3. 실패(뉴스 없음·등록 실패) 시 원인을 보고하고 같은 날 재시도하지 않는다
4. 인증 오류 시 해당 서비스의 Auth 절차를 따른다
